## How to use

Step 1: Click the Open link for your session in the table above. The notebook opens in Google Colab, so there is nothing to download.

Step 2: Before you do anything else, go to File > Save a copy in Drive. Your work is only saved in your own copy.

Step 3: Work in your copy and run each cell with Shift + Enter.

Data files for the sessions live in the data folder and load automatically from GitHub.
